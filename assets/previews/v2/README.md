# Rebuilt model and runtime captures

- `girl.png`, `face.png`, `whale.png`, `encounter.png`: orbit viewer captures.
- `cinematic-2/10/17/27/34.png`: five points in the real-time sequence.
- `game-mobile.png`: tested playable game at 720×1280.
- `deep-sea-encounter.mp4`: 180 actual WebGL renders at 540×960, encoded at 15fps
  as a 12-second compressed preview of the 36-second interactive sequence.
- `verification.json`: browser and skeletal animation checks.

These are captures of 3D geometry, not AI-generated promotional images.
They document a reference reconstruction with visible differences from the
original character and production rendering. See `../../../REBUILD_NOTES.md`.
